# 🌱 مسیر من (My Path) — نسخه ابری

اپلیکیشن شخصی مدیریت عادت‌ها، ژورنال، توصیه‌ها، برین‌استورم و باشگاه.
حالا **چند دستگاهی**: با یک حساب، روی لپ‌تاپ و گوشی وارد می‌شوی و داده‌ها
خودکار در ابر سینک می‌شوند.

**استک:** HTML + CSS + Vanilla JS + [Supabase](https://supabase.com)
(بدون React، بدون build، بدون npm)

---

## ⚡️ شروع سریع

۱. یک پروژه در Supabase بساز.
۲. فایل [`supabase/schema.sql`](supabase/schema.sql) را در **SQL Editor** اجرا کن.
۳. در [`app.js`](app.js) بالای فایل، `SUPABASE_URL` و `SUPABASE_ANON_KEY` را بگذار.
۴. آدرس اپ را در **Authentication → URL Configuration** اضافه کن.
۵. اپ را با یک وب‌سرور محلی باز کن (`file://` کار نمی‌کند) و با ایمیل وارد شو.

📘 **راهنمای کامل قدم‌به‌قدم (فارسی): [SETUP-fa.md](SETUP-fa.md)**

---

## 📁 فایل‌ها

- `index.html` — ساختار + صفحه ورود (Magic Link)
- `style.css` — طراحی، تم‌ها و استایل صفحه ورود
- `app.js` — منطق کامل + لایه‌ی داده‌ی Supabase
- `supabase/schema.sql` — جدول‌ها، ایندکس‌ها و سیاست‌های RLS
- `SETUP-fa.md` — راهنمای نصب و عیب‌یابی
- `README.md` — همین فایل

## ☁️ داده‌ها

دیگر در LocalStorage ذخیره نمی‌شوند. هشت جدول در Supabase:

| جدول | محتوا |
|---|---|
| `habits` | عادت‌ها |
| `logs` | تیک‌های روزانه |
| `journal_entries` | ژورنال |
| `advice` | تاپ توصیه‌ها |
| `brainstorm_topics` | موضوعات برین‌استورم |
| `gym_sessions` | جلسات باشگاه |
| `workout_plans` | برنامه ورزشی |
| `user_settings` | تنظیمات + یادداشت هفتگی |

همه‌ی جدول‌ها `user_id` دارند و **RLS** دارند: هر کاربر فقط داده‌ی خودش را
می‌بیند. کلید `anon` در `app.js` عمومی است و همین درست است — امنیت از RLS می‌آید.

> نسخه‌ی قبلی داده‌ها را در LocalStorage با پیشوند `mypath_` نگه می‌داشت.
> برای انتقال آن‌ها: **تنظیمات → انتقال داده‌های قبلی** (یا راهنمای قدم ۸).

## ✨ بخش‌ها

1. **🏠 داشبورد** — نمای کلی روز
2. **✅ عادت‌ها** — تیک روزانه + Streak
3. **📔 ژورنال** — ورودی‌های روزانه با Mood و تگ
4. **💡 تاپ توصیه‌ها** — دیوار توصیه‌ها (کارت رنگی + پین)
5. **🧠 برین‌استورم** — موضوع‌های جدا با بوم نوشتن طولانی
6. **💪 باشگاه** — ثبت جلسات + حرکات + کیفیت و انرژی
7. **🏋️ برنامه ورزشی** — برنامه هفتگی + بررسی عملکرد کوتاه/بلندمدت
8. **📊 آمار** — نمودار و Heatmap
9. **⚙️ تنظیمات** — تم، پالت، حساب کاربری، Export/Import

## 🧪 تست

منطق داده‌ها با یک کلاینت Supabase تقلبی و DOM آزمایشی تست شده است:

```bash
node test-smoke.js
```

این تست ورود، بارگذاری، همه‌ی ذخیره/حذف‌ها، انتقال LocalStorage و
پاک‌سازی را پوشش می‌دهد.
