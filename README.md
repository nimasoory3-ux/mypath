# 🌱 مسیر من (My Path)

اپلیکیشن شخصی مدیریت عادت‌ها، ژورنال، توصیه‌ها، برین‌استورم و باشگاه.

## 🚀 اجرا
فقط فایل `index.html` رو باز کن. هیچ نصبی لازم نیست.
> پیشنهاد: از افزونه Live Server در VS Code استفاده کن.

## 📁 فایل‌ها
- `index.html` — ساختار
- `style.css` — طراحی و تم‌ها
- `app.js` — منطق کامل
- `README.md` — همین فایل

## 💾 داده‌ها
همه در LocalStorage با پیشوند `mypath_`:
- `mypath_habits` — عادت‌ها
- `mypath_logs` — تیک‌های روزانه
- `mypath_journal` — ژورنال
- `mypath_advice` — تاپ توصیه‌ها
- `mypath_brainstorm` — موضوعات برین‌استورم
- `mypath_gym` — جلسات باشگاه
- `mypath_plan` — برنامه ورزشی
- `mypath_settings` — تنظیمات
- `mypath_weekly` — یادداشت هفتگی

## ✨ بخش‌ها
1. **🏠 داشبورد** — نمای کلی روز
2. **✅ عادت‌ها** — تیک روزانه + Streak
3. **📔 ژورنال** — ورودی‌های روزانه با Mood و تگ
4. **💡 تاپ توصیه‌ها** — دیوار توصیه‌های زندگی (کارت رنگی + پین)
5. **🧠 برین‌استورم** — موضوع‌های جدا با بوم نوشتن طولانی
6. **💪 باشگاه** — ثبت جلسات + حرکات + کیفیت و انرژی
7. **🏋️ برنامه ورزشی** — تعیین برنامه هفتگی + بررسی عملکرد کوتاه/بلندمدت
8. **📊 آمار** — نمودار و Heatmap
9. **⚙️ تنظیمات** — تم، پالت، Export/Import
